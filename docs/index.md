## Evaluation Map

| Question | Start here |
| --- | --- |
| Can this agent code? | Benchmarks and coding-agent resources |
| Can this agent use tools correctly? | Function-calling and tool-use benchmarks |
| Can this agent browse the web? | Browser and web-agent benchmarks |
| Can this agent recover from failure? | Reliability and regression resources |
| Can I monitor it in production? | Production monitoring resources |
| Is this agent safe enough? | Safety and robustness benchmarks |

## Notes

- Start with the task, not the tool.
- Treat leaderboard scores as clues, not proof.
- Prefer resources that explain the task and the scoring.
- For production work, traces and regression tests matter as much as offline scores.
