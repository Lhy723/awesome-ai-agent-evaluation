# Evaluation Frameworks

Frameworks help teams turn one-off checks into repeatable evaluation workflows.

## Open Evaluation Frameworks

- [Inspect AI](https://inspect.aisi.org.uk/) — Framework for model and agent evaluations with tools, scorers, sandboxes, and logs.
  `framework` `evals` `safety`
- [Inspect Evals](https://github.com/UKGovernmentBEIS/inspect_evals) — Community benchmark implementations for Inspect AI.
  `framework` `benchmark-registry` `safety`
- [OpenAI Evals](https://github.com/openai/evals) — Framework and registry for evaluating LLM systems.
  `framework` `llm-evaluation` `regression`
- [DeepEval](https://deepeval.com/docs/introduction) — Pytest-style LLM and agent evaluation framework.
  `framework` `testing` `agent-eval`
- [promptfoo](https://github.com/promptfoo/promptfoo) — CI-friendly prompt, model, and agent regression testing.
  `framework` `regression` `ci`
- [Ragas](https://docs.ragas.io/en/stable/) — Metrics for RAG, tool use, and agentic workflows.
  `framework` `metrics` `rag`

## Platforms and Observability

- [LangSmith](https://docs.langchain.com/langsmith/home) — Tracing, datasets, experiments, human review, and online evaluators.
  `platform` `observability` `agent-eval`
- [Arize Phoenix](https://arize.com/docs/phoenix) — Open-source tracing and evaluation workflow for AI applications.
  `platform` `observability` `evaluation`
- [Langfuse](https://langfuse.com/docs) — Open-source observability, prompt management, evaluations, and production monitoring.
  `platform` `observability` `production`
- [Braintrust](https://www.braintrust.dev/docs) — Experiments, scorers, datasets, tracing, and prompt iteration.
  `platform` `experiments` `regression`

## Standards

- [OpenTelemetry GenAI Semantic Conventions](https://opentelemetry.io/docs/specs/semconv/gen-ai/) — Standard telemetry fields for GenAI systems.
  `standard` `observability` `telemetry`
- [OpenInference](https://github.com/Arize-ai/openinference) — Instrumentation conventions for LLM, RAG, and agent traces.
  `standard` `observability` `tracing`
