# Benchmarks

This page highlights benchmark families that are especially useful for comparing AI agents.

## Coding Agents

- [SWE-bench](https://www.swebench.com/SWE-bench/) — Evaluates coding agents on real GitHub issue-resolution tasks.
  `benchmark` `coding-agent` `real-world-tasks`
- [SWE-bench Live](https://swe-bench-live.github.io/) — Uses newer software-engineering tasks to reduce contamination risk.
  `benchmark` `coding-agent` `live`
- [LiveCodeBench](https://livecodebench.github.io/) — Provides newer code-generation tasks for model and agent baselines.
  `benchmark` `code-generation` `live`

## Browser and Computer Use

- [WebArena](https://webarena.dev/) — Self-hosted realistic websites for functional browser-agent evaluation.
  `benchmark` `browser-agent` `web`
- [WorkArena](https://servicenow.github.io/WorkArena/) — Enterprise web tasks for evaluating browser agents in knowledge-work settings.
  `benchmark` `browser-agent` `enterprise`
- [OSWorld](https://os-world.github.io/) — Real desktop tasks for multimodal computer-use agents.
  `benchmark` `computer-use` `desktop-agent`
- [AndroidWorld](https://github.com/google-research/android_world) — Android task environment for mobile-agent evaluation.
  `benchmark` `mobile-agent` `computer-use`

## Tool Use

- [Berkeley Function Calling Leaderboard](https://gorilla.cs.berkeley.edu/leaderboard.html) — Function-calling benchmark across languages, APIs, and multi-turn cases.
  `benchmark` `function-calling` `tool-use`
- [tau2-bench / tau3-bench](https://github.com/sierra-research/tau2-bench) — Multi-turn customer-service tasks with tools, policies, and simulated users.
  `benchmark` `tool-use` `multi-turn`
- [ToolBench](https://github.com/OpenBMB/ToolBench) — API-oriented tool-use benchmark for LLM agents.
  `benchmark` `tool-use` `api`

## General Agents

- [GAIA](https://huggingface.co/gaia-benchmark) — General assistant benchmark requiring reasoning, tools, and external resources.
  `benchmark` `general-agent` `tool-use`
- [AgentBench](https://github.com/THUDM/AgentBench) — Multi-environment benchmark for interactive LLM agents.
  `benchmark` `general-agent` `interactive`
- [Terminal-Bench](https://www.tbench.ai/) — Terminal task benchmark for shell-using agents.
  `benchmark` `terminal-agent` `tool-use`
