# Papers

These papers are useful starting points for understanding how agent benchmarks are designed and what they actually measure.

## General and Tool-Using Agents

- [AgentBench: Evaluating LLMs as Agents](https://arxiv.org/abs/2308.03688) — Introduces a multi-environment benchmark for interactive LLM agents.
  `paper` `general-agent` `benchmark`
- [GAIA: A Benchmark for General AI Assistants](https://arxiv.org/abs/2311.12983) — Tests assistant agents on difficult questions requiring reasoning and tools.
  `paper` `general-agent` `tool-use`
- [tau-bench: A Benchmark for Tool-Agent-User Interaction in Real-World Domains](https://arxiv.org/abs/2406.12045) — Evaluates tool-using agents in policy-constrained customer-service dialogs.
  `paper` `tool-use` `multi-turn`
- [API-Bank: A Comprehensive Benchmark for Tool-Augmented LLMs](https://arxiv.org/abs/2304.08244) — Studies API-augmented LLM evaluation and training.
  `paper` `tool-use` `api`

## Coding Agents

- [SWE-bench: Can Language Models Resolve Real-World GitHub Issues?](https://arxiv.org/abs/2310.06770) — Introduces repository-level issue-resolution evaluation.
  `paper` `coding-agent` `benchmark`

## Browser and Computer-Use Agents

- [WebArena: A Realistic Web Environment for Building Autonomous Agents](https://arxiv.org/abs/2307.13854) — Introduces self-hosted realistic websites for browser-agent evaluation.
  `paper` `browser-agent` `benchmark`
- [VisualWebArena: Evaluating Multimodal Agents on Realistic Visual Web Tasks](https://arxiv.org/abs/2401.13649) — Adds visual grounding to web-agent evaluation.
  `paper` `browser-agent` `multimodal`
- [WorkArena: How Capable Are Web Agents at Solving Common Knowledge Work Tasks?](https://arxiv.org/abs/2403.07718) — Evaluates web agents on enterprise tasks.
  `paper` `browser-agent` `enterprise`
- [OSWorld: Benchmarking Multimodal Agents for Open-Ended Tasks in Real Computer Environments](https://arxiv.org/abs/2404.07972) — Evaluates desktop computer-use agents with execution-based checks.
  `paper` `computer-use` `benchmark`

## Safety

- [AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents](https://arxiv.org/abs/2406.13352) — Measures utility-security tradeoffs under prompt-injection attacks.
  `paper` `safety` `prompt-injection`
- [AgentHarm: A Benchmark for Measuring Harmfulness of LLM Agents](https://arxiv.org/abs/2410.09024) — Tests harmful behavior in agentic settings.
  `paper` `safety` `agent`
